# Security Policy

## Supported Versions

Only the latest release of Paatalashala is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

---

## Reporting a Vulnerability

We take the security of Paatalashala seriously. If you find a security vulnerability, please do **not** open a public issue. Instead, report it privately via email:

* Send vulnerability reports to: **srisatyalokesh@gmail.com**
* Please include a detailed description of the vulnerability, steps to reproduce it, and potential mitigations.

### What to Expect
* We will acknowledge receipt of your report within 48 hours.
* We will investigate and coordinate a security release containing a fix as quickly as possible.
* You will be kept updated on our progress, and we will credit you for finding the issue once the patch is published.

Thank you for helping keep Paatalashala secure!
